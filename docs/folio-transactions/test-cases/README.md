# Folio Transactions Test Cases

This folder is reserved for black-box documentation of folio transaction behavior.

| Coverage type | Planned scenarios |
|---|---|
| Good | Folio initialization, nightly actualization, payments, refunds, settlement, invoice generation |
| Bad | Unauthorized posting, invalid categories, locked-date posting, unsettled checkout |
| Edge | Retry-safe posting, reversals, partial payment, zero balance, forecast reconciliation |
