# Night Audits Test Cases

This folder is reserved for black-box documentation of night audit behavior.

| Coverage type | Planned scenarios |
|---|---|
| Good | Clean close, nightly posting, journal creation, report generation, next-date opening |
| Bad | Blocking conditions, missing General Ledger mappings, locked next date, failed close |
| Edge | Concurrent runs, retries, force roll, no-show processing, closed-date overrides |
